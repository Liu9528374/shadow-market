# 演示夹具（dev fixtures）

> 用途：`market/data/catalog.json` **不可用**（还没生成 / 静态托管路径不对）时，让市场页面仍可演示与验收界面。
> **这不是线上真实数据**：页面会一直显示「演示夹具」标记，卡片带红色「演示夹具」徽标，绝不冒充真实资源。

## 内容

| 文件 | 说明 |
|---|---|
| `catalog.json` | 5 个资源：3 个课程包（有真实可 fetch 的夹具包）+ 1 个字幕包（30 积分兑换演示，无 packageUrl）+ 1 个未知类型 `collection`（验证降级通用卡） |
| `packages/fixture-*.shadowcourse` | 3 个演示课程包（单文件 JSON，`spec: "shadow.course"`），句子时间轴自洽 |

## 如何加载

- 数据缺失时：首页错误态点「加载演示夹具（界面演示）」；
- 或直接访问：`http://127.0.0.1:18920/?fixture=1#/`（hash 内 query 也支持：`#/?fixture=1`）；
- 退出：点击顶部横幅「退出夹具 · 重试真实数据」。

## 边界

- 演示夹具只服务于界面降级与前端自测；真实交付物是 `market/data/**`（由 shadowcourse 打包器生成）。
- 夹具内容仅用于测试，不含第三方影视 / 音乐素材；媒体一律 BYOM（包内不含媒体）。
