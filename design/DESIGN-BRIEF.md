# SHADOW 市场 · UI 重设计 Brief（Obsidian & Amber · 个人工作台优先）

> 版本：v1（2026-11-01）｜负责人：Lead｜本文件是设计阶段的唯一方向来源；**设计定稿并获用户批准前不改产品代码**。
> 背景：用户反馈现有市场 UI「太丑、又杂又乱」；要求：①学习 5 个网站的布局（要美感）②进入网站首先是**个人界面（像 GitHub 登录首页）**③**右侧栏可以进入市场**④在 GitHub 搜索并下载设计 skill/素材包后再动手。

---

## 1. 诊断：现站为什么「杂、乱」

1. **容器过多**：通知条 + 分类侧栏 + 标签云 + 类型筛选 + 快捷入口 + 推荐列表 + 最新列表共存，视觉上全是盒子/边框/分割线，没有主次。
2. **层级平坦**：几乎所有文字 13–14px、同样字重；标题与正文差距小，扫读找不到焦点。
3. **导航重复**：顶部导航、侧栏「关于市场/一键导入说明/积分/设置」、移动端快捷按钮、底部导航同时出现，入口冗余。
4. **强调色泛滥**：品牌橙 + 绿/紫/蓝资源封面色 + 多种徽标色，颜色多但没有节奏。
5. **右栏缺失**：桌面没有右侧信息栏；用户要的「右侧栏进市场」没有承载位。
6. **空态/说明文案堆在正文**：BYOM/免费/积分提示以长条横幅出现，挤占首屏。
7. **移动端更挤**：筛选 chip 三行 + 两排按钮 + 通知条，首屏看不到内容。
8. **个人信息不存在**：首页是「探索市场」，没有「我的」归属感（GitHub 首页 = 个人工作台）。

## 2. 设计方向：Obsidian & Amber（黑曜石 + 琥珀）

- **一句话**：一个安静、温暖、有质感的个人影子跟读工作台；市场是工作台右侧的一扇门，而不是一进门就掉进商品列表。
- **气质关键词**：calm / warm / editorial / precise / spacious。参考 Linear 的克制、GitHub 的信息架构、Vercel 的排版、Stripe 的内容秩序、Raycast 的暗色质感。
- **默认深色，浅色可选**：深色 = 品牌图标的黑底 + 暖橙；浅色 = 暖纸（warm paper），不是冷白。
- **减法**：默认无边框卡片（用表面色差 + 阴影分层）；只有可交互控件出现边框；一屏最多 1 个主 CTA。
- **品牌母题**：Voice Wave 的五段声波（取自 APP 图标）作为装饰性图形（封面/空态/CTA 背景），颜色只允许琥珀系。
- **反模板**：禁止紫蓝渐变、禁止 emoji 当图标、禁止圆角胶囊滥用、禁止玻璃拟态雾化到看不清。

## 6. 设计 Token（Lead 在 `design/mockups/styles/tokens.css` 定稿）

### 6.1 颜色（深色默认）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B0B0E` | 页面底色（暖黑） |
| `--bg-1` | `#111114` | 侧栏/顶栏面板 |
| `--bg-2` | `#17171B` | 卡片 |
| `--bg-3` | `#1E1E24` | hover/选中 |
| `--line` | `#26262C` | 极细分割线（慎用） |
| `--line-strong` | `#35353E` | 输入框/控件边框 |
| `--text` | `#F4EFE8` | 主文字（暖白） |
| `--text-2` | `#B7B1A8` | 次要文字 |
| `--text-3` | `#807A72` | 弱文字/标签 |
| `--amber` | `#FFB55C` | 品牌强调（图形/高亮） |
| `--amber-strong` | `#F0913B` | hover/渐变中段 |
| `--amber-deep` | `#E27418` | 渐变末段/深强调 |
| `--amber-ink` | `#1A1208` | 橙底上的深色文字 |
| `--amber-soft` | `rgba(255,181,92,.12)` | 选中态底/徽标底 |
| `--success` | `#7FD99A` | 成功/免费 |
| `--danger` | `#FF7A6B` | 错误 |
| `--info` | `#8AB8FF` | 信息（少用） |

浅色（暖纸）：`--bg:#FAF7F2` `--bg-1:#FFFFFF` `--bg-2:#FFFFFF` `--bg-3:#F3EEE7` `--line:#EAE3D8` `--line-strong:#D8CFC1` `--text:#211E1A` `--text-2:#6B655C` `--text-3:#8F887E` `--amber:#E88A2E` `--amber-strong:#C2410C`（文字/主按钮用深橙保证对比） `--amber-ink:#FFFFFF`。
**规则**：正文对比 ≥4.5:1；强调色只用于 1 个主动作 + 少量状态；资源封面色只用琥珀/暖灰 5 档，禁止绿紫蓝。

### 6.2 字体与字号

- 拉丁：**Inter**（设计素材包下载，woff2）；中文：`"PingFang SC","Noto Sans SC","Microsoft YaHei"` 系统栈；等宽数字：`ui-monospace,"JetBrains Mono",Consolas`。
- 字阶：display 34/40（-0.02em, 600）；h1 28/36；h2 22/30；h3 17/24；body 14/22；small 13/20；micro 12/16；标签 micro + letter-spacing .06em 大写。
- 标题字重 600，正文 400，数字/统计 600 + tabular-nums。

### 6.3 间距 / 圆角 / 阴影 / 动效

- 间距：4 基数（4/8/12/16/24/32/48/64）；区块间距 32；卡片内 padding 20–24。
- 圆角：控件 10、卡片 16、大卡 20、头像圆、胶囊 999（仅状态/小标签）。
- 阴影（深色）：卡片 `0 1px 0 rgba(255,255,255,.03) inset, 0 12px 32px rgba(0,0,0,.28)`；悬浮 +1px 上移；浅色用暖灰软阴影。
- 动效：160ms `cubic-bezier(.2,.7,.2,1)`；hover 只做位移/亮度；`prefers-reduced-motion` 全部关闭。
- 焦点：`outline:2px solid var(--amber); outline-offset:2px`。

### 6.4 组件语言

- **Button**：primary（琥珀渐变 + 深字，40px 高，radius 10，600）；secondary（透明 + `--line-strong` 边框）；ghost（无底，text-2）；icon-button（36×36 圆形，hover bg-3）。
- **Card**：bg-2，radius 16，无边框（浅色可 1px `--line`），padding 20–24；hover：translateY(-1px)+阴影。
- **Resource card**：封面 88×88 或顶部 16:9（CSS 渐变 + 声波母题）；标题 16/600；副标 13/`--text-3`；标签行 micro；底部 meta（句数/时长/更新）+ 收藏 icon。
- **Badge**：micro 11px，dot/文字，琥珀 soft 底；状态类不用彩虹色。
- **Sidebar item**：36px 高，radius 10，icon 18px；active = `--amber-soft` 底 + `--amber` 文字 + 左侧 2px 指示条。
- **Tabs**：下划线式 2px 琥珀，间距 24，选中文字 600。
- **Table/List**：行高 52，hover bg-3，分割线只用 `--line`。
- **Empty state**：声波线稿（CSS/SVG）+ 一句说明 + 一个主 CTA。
- **Profile chip**：圆形头像（品牌图标）+ 名称「影子练习者」+ 「本机访客 · 未登录」+ 设置齿轮。

## 7. 各屏要求（设计稿）

### 7.1 个人工作台（index.html）— 最重要
- Header：品牌 icon+「SHADOW 市场」+ `PERSONAL` micro；中间搜索；右侧积分胶囊「120 积分」、主题、EN、头像。
- 左栏：导航（工作台 active / 市场 / 我的收藏 / 我的资源 / 积分 / 投稿 / 设置）；下方「最近访问」2 条资源小行。
- 主区：`下午好，影子练习者`（display）+ 副句「今天也练 10 分钟吧」+ 匿名徽标；4 个数据 tile（积分 / 收藏 / 已下载 / 连续练习天数）——数字大、标签小、无边框、用底色差分隔。
- 「继续上次」宽卡：资源名 + 进度条 + 「继续练习」+ 「打开导入文件」两个动作；无记录时显示优雅空态（声波线 + 去市场逛逛）。
- 「为你推荐」2×2 资源卡（来自真实 catalog 7 条）。
- 「最近动态」时间线（下载/收藏/打卡 3–4 条）。
- 右栏：**进入市场大卡**（`进入市场 · 发现 7 个免费资源` + 箭头 + 声波纹理）、热门标签（B1/日常/连读/职场/字幕）、平台动态（更新日志）、合规小卡。
- 深浅两版都要好看；默认深色。

### 7.2 市场（market.html）
- 顶部：面包屑「市场」+ 标题「发现资源」+ 副标（全免费 · BYOM · 7 个资源）+ 搜索框（大）。
- 左栏：筛选分组（类型 / 难度 / 分类 / 标签）默认只展开类型，其他折叠（chevron），计数在右；「清除筛选」。
- 主区：排序（最近更新 / 名称 / 下载）+ 视图切换（grid/list 仅示意）；资源卡网格 2 列（≥1280 可 3 列？定 2 列 + 大卡更舒展）；空态。
- 右栏：「进入工作台」卡 + 热门分类 + 创作者（SHADOW Studio）+ 投稿入口。
- 不允许：标签云、三行 chip、重复按钮。

### 7.3 资源详情（resource.html）
- 左主区：面包屑 → Hero（大图标 + 标题 + 副标 + 徽标 Free/BYOM/v1.0.0/B1 + 作者行 + 更新时间）→ 操作行（主按钮「下载导入」+ ghost「收藏」+ icon「分享」）→ Tabs（简介 / 句子预览 5 / 文件 4 / 版本与变更 1）→ README 正文（含引用块、列表、代码）、句子预览表。
- 右栏：下载导入卡（三产物：`.shadow.json` 推荐 → `.srt` 备选 → `.shadowcourse` 规范；BYOM 提示 + 5 步 3 坑折叠「查看导入步骤」）；许可卡（CC-BY-4.0 + 权利依据）；统计卡（5 句 / 0:22 / 40 词 / 6.1KB / SHA256 前 12 位）；反馈/投诉小链接。
- 操作要少而清晰；长说明收进折叠/右侧卡，不铺在标题下。

### 7.4 我的资源 / 收藏（library.html）
- Tabs：已下载 / 收藏 / 最近导入（带计数）。
- 列表行：封面缩略 + 标题 + 类型/难度 + 最近时间 + 行内操作（打开详情 / 删除/取消收藏）；空态（收藏为空 → 去市场看看）。
- 右栏：沿用工作台右栏（进入市场/热门标签）。

### 7.5 积分中心（points.html）
- 顶部：积分余额大数字 + 「免费获取 · 不可购买/转让/提现」说明（小字，非横幅）。
- 3 个获取动作卡：每日签到 +5 / 完成练习打卡 +10 / 首次导入 +20（P1 演示标签）。
- 流水列表（时间/动作/±积分/余额）；「兑换记录 / 我的资源」链接。
- 右栏：积分规则摘要 + 进入市场 CTA。

### 7.6 投稿指南（contribute.html）
- 编辑式布局：左目录（sticky）+ 正文（≤720px，行高 1.75）；章节：可以投什么 / 版权与 BYOM / 格式与校验 / 审核与下架 / 提交方式。
- 引用块、编号步骤、代码块（`node tools/shadowcourse/validate.mjs`）样式精致；顶部一句「全免费 · 人工审核 · 保留投诉下架」。

### 7.7 移动端（mobile.html）
- 两张 390 宽帧：个人工作台 + 市场。
- Header 56：logo + 搜索 icon + 头像；主内容单列；数据 tile 2×2；「继续上次」卡；推荐卡单列；底部导航 4 项（工作台/市场/收藏/更多）+ 中间「积分」徽标可选。
- 市场：顶部搜索 + 筛选 chips 单行横滑（不得三行）+ 列表 2 列（或单列大卡）；底部导航保留。
- 详情：Hero 简化 + 吸底操作条（下载导入 / 收藏）。

## 9. 设计验收（用户批准前自检）
