## 0. 一页结论

1. **从「一进门就是商品列表」改为「一进门是我的工作台」**：`#/` = 个人工作台（问候 + 匿名资料 + 4 数据 tile + 继续上次 + 为你推荐 + 最近动态）；市场移到 `#/market`；所有桌面页统一 **248 / 744 / 320** 三栏，**右栏第一卡 = 「进入市场」**（唯一渐变面），市场页镜像「进入工作台」。
2. **美感的来源不是装饰，而是纪律**：单一容器（1360）、7 档字阶、颜色预算（琥珀 + 中性 + 1 状态）、无边框卡片 + 一种阴影、区块 32–48 ≫ 卡间 16–24 ≫ 卡内 20–24、每屏 1 个主 CTA。
3. **两套主题**：默认「黑曜石」暖黑 + 琥珀（与 Voice Wave 图标同源），可选「暖纸」浅色；两套都通过同一 tokens 体系切换。
4. **5 站布局各有取用**：GitHub（个人工作台三栏 + 右栏轻结构）、Linear（暗色 3 层表面 + 字阶/留白）、Vercel（负字距大标题 + 无边框 + 大留白）、Stripe（两层导航 + 右栏「决策卡」）、Raycast（单一卡片材质 + 光效纪律 + ⌘K）。
5. **素材与 skill 来自 GitHub 并已下载归档**：anthropics/skills（frontend-design 等 4 个）、ui-ux-pro-max-skill、hallmark（anti-AI-slop）、huashu-design、awesome-design 索引；Lucide 图标 43 个、Inter/JetBrains Mono 字体、radix colors/open-props/modern-normalize 参考；全部宽松许可、可追溯（`design/assets/INVENTORY.md`）。
6. **设计稿 8 个页面已渲染**：个人工作台（深/浅）、市场（深/浅）、详情（深/浅）、我的资源/收藏（深/浅）、积分（深/浅）、投稿（深/浅）、移动首页、移动市场。
7. **下一步**：用户批准后按 §11 实施映射改代码（保留 catalog v2/PWA/i18n/导入产物/QA），再跑 E2E + Lighthouse 回归。

## 3. 设计方向「Obsidian & Amber」

- **一句话**：安静、温暖、精确的个人影子跟读工作台；市场是工作台右侧的一扇门。
- **气质**：calm / warm / editorial / precise / spacious。
- **默认深色**：暖黑 `#0A0A0C` 基底 + 琥珀 `#FFB55C`；浅色 = 暖纸 `#F7F3EC` + 深橙 `#C2410C`（文字/按钮保证对比度）。全部走 tokens。
- **品牌**：Voice Wave 五段声波作为唯一装饰母题（CSS/SVG 生成，不引第三方插画）；品牌橙只给「进入市场/工作台」CTA、主按钮、焦点环、极少数状态。
- **反模板清单（来自 hallmark skill + 我们 brief）**：禁紫蓝渐变、禁 emoji 图标、禁全屏玻璃拟态、禁每张卡不同圆角/阴影、禁三行 chip 云、禁 12px 以下中文正文、禁双主 CTA、禁参考站视觉克隆。
- **「一切即插件」在视觉上的体现**：资源类型（课程/字幕/插件说明）只通过「封面母题 + 类型徽标 + 详情 Tab 集合」区分，不引入新配色。

## 4. 信息架构（个人工作台优先）

```
#/                个人工作台（Personal Dashboard）   ← 进站默认
#/market          市场探索（右侧栏/左栏入口）
#/resource/:id    资源详情（Tabs: 简介/句子预览/文件/版本与变更）
#/library         我的资源 · 收藏（已下载/收藏/最近导入）
#/points          积分中心（P1 演示）
#/contribute      投稿指南
#/about #/privacy #/complaint #/changelog #/import #/settings #/404
```

- **桌面骨架**：header 64（品牌 + 搜索 + 积分 + 主题 + EN + 头像）→ 左栏 248（工作台/市场/收藏/我的资源/积分/投稿 + 最近访问 + 设置）→ 主列 744 → 右栏 320。
- **右栏（sticky top 88）≤3 块**：
  1. **「进入市场」大卡**（唯一渐变面：声波母题 + 7 个免费资源 + 箭头）；
  2. 热门标签（5 个，chip，不是云）；
  3. 合规/放心卡（BYOM / 全免费 / 无强制登录 + 隐私链接）。
  > 工作台主区已有「最近动态」，原右栏「平台动态」卡取消（研究修正）。
- **市场页**：左栏从「导航」切为「筛选」（类型/难度/分类/标签，默认只展开类型，其余折叠）；右栏镜像「进入工作台」卡 + 热门分类 + 创作者 + 投稿。
- **详情页**：主列 Hero + 操作 + Tabs + README + 句子预览；右栏 3 块：下载导入（3 产物 + BYOM 5 步 3 坑折叠）/ 统计 / 许可。
- **移动端**：header 56（logo + 搜索 + 头像）；单列；底部导航 4 项（工作台/市场/收藏/积分）；详情用吸底操作条（64）**替换** bottom-nav；筛选 chips 单行横滑。

## 6. 设计系统 Tokens（实现即 `design/mockups/styles/tokens.css`）

### 6.1 颜色

| Token | 深色（默认） | 浅色（暖纸） | 用途 |
|---|---|---|---|
| `--bg` | `#0A0A0C` | `#F7F3EC` | 页面底 |
| `--bg-1` | `#101013` | `#FFFFFF` | 侧栏/顶栏面板 |
| `--bg-2` | `#141418` | `#FFFFFF` | 卡片 |
| `--bg-3` | `#1B1B21` | `#F1EBE1` | hover/选中 |
| `--line` / `--line-strong` | `#24242B` / `#34343E` | `#E9E1D5` / `#D5C9B8` | 极细分割 / 控件边框 |
| `--text` / `--text-2` / `--text-3` | `#F5F0E9` / `#B9B2A8` / `#7E7972` | `#1E1B17` / `#6A6359` / `#8C857A` | 主/次/弱文字 |
| `--amber` / `--amber-2` / `--amber-3` | `#FFB55C` / `#F0913B` / `#E27418` | `#E88A2E` / `#C2410C` / `#9A3412` | 品牌强调 |
| `--amber-ink` | `#1A1208` | `#1A1208` | 橙底上的深色文字（两主题一致，保证对比） |
| `--success` / `--danger` | `#7FD99A` / `#FF7A6B` | `#2F8F4E` / `#C0362C` | 仅状态 |
| 封面 5 档 | 琥珀/暖灰渐变 | 暖纸渐变 | 资源封面（禁绿紫蓝） |

纪律：强调色只用于 1 个主 CTA + 少量状态；渲染色预算 ≤14；正文对比 ≥4.5:1、非文本 ≥3:1。

### 6.2 字体与字阶

- 拉丁 **Inter**（Variable，OFL-1.1，本地 woff2）；中文系统栈 PingFang/Noto Sans SC/Microsoft YaHei；数字/代码 **JetBrains Mono**（OFL-1.1）。
- 7 档：display **34/40**（−0.02em，600）｜h1 **28/36**｜h2 **22/30**｜h3 **17/24**｜body **14/22**｜small **13/20**｜micro **12/16**；11px 只用于 uppercase 标签（ls .06em）。
- 数字 600 + tabular-nums；标题 600–650；正文 400；不要 300（中文小字会糊）。

### 6.3 间距/圆角/阴影/动效/焦点

- 间距 4 基数：4/8/12/16/20/24/32/40/48/64；区块 32–48；卡间 16–24；卡内 20–24。
- 圆角：控件 10 / 卡片 16 / 大卡 20 / 头像全圆 / pill 999（仅状态）。
- 阴影：深色 `0 1px 0 rgba(255,255,255,.03) inset, 0 12px 32px rgba(0,0,0,.3)`；浅色暖灰软阴影；全站 1 种材质。
- 动效 160ms `cubic-bezier(.2,.7,.2,1)`，只动 transform/opacity；`prefers-reduced-motion` 全关。
- 焦点：`0 0 0 2px var(--bg), 0 0 0 4px var(--amber)`；键盘可达；触控目标 ≥24（移动底栏 ≥44）。

### 6.4 组件清单（实现见 `base.css`）

顶栏（品牌/搜索/kbd/积分胶囊/icon-btn/头像）、左栏（分组/项/count/最近访问/设置）、右栏卡、CTA 大卡、按钮（primary/secondary/ghost/icon/sm）、徽标（soft/outline/neutral/success）、chip、资源卡（封面/徽标/标题/副标/描述/标签/meta/收藏）、Hero、Tabs、列表行、统计 tile、进度条、时间线、空态（声波线稿 + 1 CTA）、通知条（内联单行）、Profile hero、继续上次卡、移动底栏。

## 9. 无障碍与性能底线（实施时保持）

- 键盘：所有交互可达；Tabs 方向键/Home/End；命令面板 ↑↓/Esc；焦点环可见；跳转主内容链接。
- 语义：页面唯一 h1；标题层级连续；列表/分页语义；表单 label/aria-labelledby；图片 alt（装饰性 `alt=""` + aria-hidden）。
- 对比：正文 ≥4.5:1；非文本 ≥3:1；深浅两套分别验证。
- 动效：160ms；`prefers-reduced-motion` 全关；无自动播放/闪烁。
- 性能预算：延续 P0 的 Lighthouse 目标（移动端 Performance ≥90、Accessibility ≥90、CLS<0.1、0 console error）；字体 woff2 本地、`font-display:swap`；图标内联 SVG（无图标字体）；无第三方 CDN/分析；PWA 缓存不变。

## 12. 风险与待拍板

1. **默认主题**：设计默认深色（与品牌图标一致）；浅色为可选。若你更想要默认浅色，实施时改 `data-theme` 默认值即可（成本低）。
2. **个人工作台的数据**：P0 无账号，工作台数据来自本机 localStorage（收藏/积分演示/下载记录）；「匿名资料卡」不做假头像/假身份，显示「本机访客·未登录」。
3. **字体体积**：Inter Variable 352KB + JetBrains Mono（按需）；若在意首屏，可只内嵌 Inter Variable，数字用系统 monospace（P1 优化）。
4. **移动端导航**：当前设计 4 项（工作台/市场/收藏/积分）；如觉得「投稿/设置」需要更多入口，可改 5 项（移动底栏上限 5）。
5. **参考站截图**仅内部研究，不随产品分发；Lucide ISC 已在许可清单标注。
