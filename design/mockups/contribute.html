投稿指南

把你做的影子跟读课程包放进 SHADOW 市场。我们只收录自有 / 授权 / 公版 / CC 的纯数据包，由人工审核后上架。

全免费 人工审核 · ≤3 个工作日 保留投诉下架 更新于 2026-11-01

01可以投什么

市场只分发纯数据资源包：句子时间轴 + 中英翻译 + 练习配置，不包含任何媒体文件。用户用自己的媒体（BYOM）在 SHADOW Studio 里完成绑定与练习。

类型内容与要求示例
课程包 5–20 句；句级时间轴（start/end）；英文原文 + 中文翻译；可选重音/连读提示。对应 type: "course"。 在咖啡店点单 · B1
字幕包 SRT 时间轴或字幕 JSON；中文翻译可选；不得含影视原片片段或第三方字幕。 社区图书馆的一天 · B1
插件说明 只收声明式 JSON：内置类型 / 能力 / 权限声明，权限全部为 false，不含任何 JS / WASM / 二进制。 内置插件白名单
什么不适合市场

影视原片、YouTube / 播客的第三方片段及其字幕；未授权教材、音频或付费课程内容；需要联网执行、上传用户数据的插件；任何以 DRM、付费墙为前提的内容。

02版权与 BYOM

每一个资源都必须在元数据里声明 license 与 rights.basis，并保留可核验的权利依据。人工审核会逐条确认；无法说明来源的投稿会被退回。

允许的许可

  • own · 自有内容（文本、翻译、时间轴均为你创作）。
  • licensed · 已获得书面授权，需附证据链接或授权说明。
  • public-domain · 公有领域，注明来源与判定依据。
  • CC-BY / CC-BY-SA / CC0 等 CC 系列，注明版本与署名要求。

BYOM：媒体由用户自备

包内不得包含视频、音频、截图或 base64 媒体；也不得记录作者本机的绝对路径。mediaMode 固定为 byom，用户导入后用同名媒体完成绑定。

  • 已声明 license 与 rights.basis
  • 文本 / 翻译 / 时间轴均为原创或已授权
  • 包内无媒体、无第三方影视片段、无外链媒体
  • README 中说明媒体名（与 clip.name 逐字一致）

03格式与校验

课程包为单个 JSON（.shadowcourse，spec: "shadow.course"，UTF-8 无 BOM，≤2 MiB）。提交前请在本机跑一次校验，确保时间轴、字段与纯数据约束全部通过。

  1. 准备资源包与元数据 按 docs/53 的字段生成 .shadowcourse；同时准备标题、副标、分类、难度、标签、作者、许可与更新说明。
  2. 运行校验器 任何 FAIL 都先修复；校验器同时检查 end > start、时间轴升序、纯数据（无脚本 / iframe / 内联事件）与 ≤2 MiB。
  3. 生成导入产物（可选，推荐） 同时提供 .shadow.json（带翻译的 r19 工程）与 .srt（备选），并在 README 写清 5 步 + 3 个坑。
终端 · 本地校验PowerShell / bash
# 1) 校验单个课程包（或整个目录）
node tools/shadowcourse/validate.mjs --dir content/packages

# 2) 生成 / 校验 catalog（构建期会写入 sha256 与 sizeBytes）
node tools/catalog/build-catalog.mjs
node tools/catalog/validate-catalog.mjs

# 3) 生成 .shadow.json 与 .srt 导入产物（可选）
node tools/import/build-shadow-json.mjs

提示：校验通过后，构建脚本会为每个版本写入 sha256 与 sizeBytes，用户下载时可核对完整性。

04审核与下架

市场是人工运营的免费资源站，不设自动上架。审核关注三件事：版权可核验、纯数据无媒体、内容质量与安全。

  1. 机器预检 构建期自动检查 schema、引用完整性、SHA256 / 文件大小、纯数据扫描（脚本 / iframe / 外链媒体）与敏感词初筛。
  2. 人工初审（≤3 个工作日） 核对 license / rights / evidenceUrl、内容质量、标签与分类准确性；必要时邮件沟通修改。
  3. 上架与版本更新 首次上架记为 v1.0.0；后续更新递增版本并在 changelog 写明变更。
投诉与下架（始终保留）

投诉邮箱 24 小时内确认受理；疑似侵权资源 48 小时内下架；7 日内完成复核与反通知流程。重复侵权累计 3 次封禁投稿资格。

05提交方式

把以下内容打包成一封邮件（或按仓库 PR 流程提交），审核通过后会给你一个上架确认与资源链接。

  • .shadowcourse 资源包（校验器 PASS）
  • 元数据 JSON：标题 / 副标 / 描述 / 分类 / 难度 / 标签 / 语言 / 作者 / 许可
  • rights.basis 与证据链接（自有可写 own + 说明）
  • 可选：.shadow.json / .srt / 导入说明 README / 媒体名提示
邮件格式纯文本模板
主题： [投稿] 在咖啡店点单 · 课程包 · B1

正文：
- 资源名称 / 副标 / 一句话描述
- 类型： course | subtitle | plugin
- 许可： CC-BY-4.0（rights.basis: own）
- 校验结果： validate.mjs PASS（粘贴最后 10 行输出）
- 附件： resource.shadowcourse / metadata.json / README.md

提交后如 3 个工作日未收到回复，可再发一封跟进邮件；不收取任何费用，也没有加急通道。
